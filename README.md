
Pakistan National Council of the Arts (PNCA) – Institutional Website Redesign

A professional, responsive, and highly interactive institutional website for the Pakistan National Council of the Arts (PNCA). Developed as a capstone project during my web development learning journey, this project moves away from a traditional "clone" approach to deliver a completely original, immersive user experience inspired by Pakistan's rich art, culture, and heritage.

Project Vision & Identifying the Gap

While researching PNCA’s existing digital footprint, I identified several critical areas ripe for modernization. Instead of duplicating the current site, I engineered a ground-up design solution to address these gaps:
• Modern UI & Visual Presentation: Elevated the aesthetic appeal to mirror the creativity of a national arts council.
• Streamlined Content Navigation: Restructured information hierarchies for intuitive browsing.
• Flawless Responsiveness: Optimized layouts across all device breakpoints for a seamless mobile and desktop experience.
• Immersive Interaction & Motion: Leveraged GSAP animations to create engaging, fluid transitions that feel like an interactive art gallery.
• Enhanced Event Booking: Conceptualized a smoother, modern workflow for viewing and booking cultural events.

Tech Stack & Concepts Applied

• Core Structure: Semantic HTML5
• Advanced Styling: Responsive CSS3 (Flexbox, CSS Grid, Custom Media Queries)
• Dynamic Logic: Vanilla JavaScript & Advanced JS (DOM manipulation, asynchronous logic, event handling)
• Motion Design: GSAP (GreenSock Animation Platform) for high-performance scroll triggers, staggers, and timeline-based animations.

Key Features

• Cultural Landing Page: A striking, narrative-driven homepage featuring fluid GSAP entrance animations.
• Interactive Media Gallery: Dynamic presentation of visual arts, heritage exhibitions, and performing arts.
• Revamped Event Center: A clean, intuitive dashboard displaying upcoming theatre plays, musical nights, and exhibitions with conceptual booking interactions.
• Responsive Architecture: Built fluidly to ensure the integrity of the design is preserved on screens of all sizes.
